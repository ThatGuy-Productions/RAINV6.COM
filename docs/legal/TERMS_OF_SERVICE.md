## 2. Service Description

### 2.1 What RAIN Does

RAIN V6 is an AI-powered audio mastering tool that:

- Processes user-uploaded audio files through a 16-stage DSP pipeline
- Applies neural inference (RainNet v2 ONNX model) or heuristic parameter generation
- Performs loudness normalisation, EQ, multiband compression, stereo enhancement, and spectral repair
- Produces mastered audio outputs (24-bit WAV, 320 kbps MP3)
- Generates optional DDEX ERN 4.3.2 distribution packages
- Generates ISRC/UPC identifiers for local package assembly
- Provides RAIN-CERT Ed25519 provenance certificates
